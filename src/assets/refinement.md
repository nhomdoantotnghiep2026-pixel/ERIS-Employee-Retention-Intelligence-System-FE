==================================================
DESIGN REFERENCE CHARACTERISTICS
==================================================

Follow the visual philosophy of the supplied HR software reference.

The reference feels human-designed because:

- the interface is compact
- content density is relatively high
- navigation is practical
- typography is restrained
- page titles are not oversized
- controls are relatively small
- cards have modest corner radius
- most content is aligned to practical work tasks
- charts coexist with tables and filters
- there is no unnecessary visual decoration
- information hierarchy comes primarily from typography and spacing
- blue is used as the primary system color
- additional colors communicate data or status
- components look like conventional business software controls

Apply these principles to ERIS.
